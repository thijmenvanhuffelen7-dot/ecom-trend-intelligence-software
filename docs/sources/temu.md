# Bron: Temu — afgewezen

| | |
|---|---|
| Connector-id | `temu` (manifest `mp_temu`) |
| Type | partner_api |
| Juridische status | **rejected** |

Temu biedt geen openbare product- of affiliate-API voor marktonderzoek. Hun partner-API's zijn alleen voor verkopers die hun eigen catalogus beheren. Scrapen van temu.com valt buiten onze uitgangspunten: geen omzeiling van logins of anti-botmaatregelen, en de servicevoorwaarden verbieden geautomatiseerde toegang.

De connector staat in het register zodat zichtbaar is dat de bron bewust is afgewezen. Hij is uitgeschakeld en de productie-guard weigert hem. Als Temu een officiële API aanbiedt, herzien we dit besluit.
